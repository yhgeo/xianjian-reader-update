# 照玄微

一个把「段落评论」嵌进正文的阅读器：每段末尾显示评论数，点一下就能看这一段读者的讨论，像弹幕一样跟着剧情走。

支持 iPhone / iPad 和 Android，两个版本可共存安装（包名不同，各自独立更新）。

> **本应用不提供任何内容。** 应用内展示的正文、段评、时间线等全部资料，
> 均来源于公开网络，由程序整理后呈现；版权归原作者及原平台所有。

## 第一次使用（正式版）

1. **安装并打开** —— 第一次会显示「等待授权」
2. **导入书籍数据** —— 点「选择书籍数据」，选中随附的数据文件；也可以把文件放进 App 的「文件」目录后重新打开
3. **输入口令** —— 如果数据带口令，会弹窗要求输入（数据是按设备加密的，口令和本机设备都要对得上）
4. **等管理员批准** —— 批准后在 App 里点「重新校验」，就能开始读了

书籍数据通常有三个文件：**正文**、**评论**、**时间线**。正文和评论都要导入，段末才会显示评论数；
时间线是可选包，导入后章节标题下会显示年份和出场人物。加密版只接受加密数据包。

体验版跳过以上全部步骤，装好打开就能读。

## 怎么用

| 操作 | 效果 |
|---|---|
| **单击段落** | 打开这一段的评论（段末的数字是评论数） |
| **单击章节标题** | 看整章的讨论（本章说） |
| **长按屏幕** | 呼出 / 收起悬浮顶栏（目录、搜索、设置都在这里） |
| **上下滑动** | 连续滚动阅读，读完一章自动接下一章 |
| **左右滑动**（安卓，开启「分页翻书」后） | 一页一页翻，翻到章末直接接下一章 |
| **在顶栏上向上滑** | 顶栏非常驻时，可以主动把它收起来 |
| **目录按钮** | 按 8 卷分组跳转，可以折叠；另有「番外」和「建议阅读章节」入口 |
| **搜索** | 全文搜正文，点结果直接跳到那一段 |
| **评论面板下滑** | 关闭评论 |
| **章标题下的时间卡片** | 显示本章发生在「捡鉴」哪一年、出场人物的年龄 / 世代 / 修为 |

> 安卓「分页翻书」模式下**只靠滑动翻页**：点击一律留给段评，避免误触。

设置里可以调字号、行距、页边距、段落间隔，切换纸白 / 米黄 / 夜间三种背景；
顶栏进度可以选「本章 / 本卷 / 全书」，也可以让它只显示章节名、或一直常驻。
时间线可以单独开关：章标题下的年份与人物、顶栏的年份，以及世次显示用「第N代」还是「第N世」。

阅读位置会自动记住，下次打开直接回到上次读到的地方；换字号重排后仍会停在原来的段落。

## 常见问题

**打开后显示「等待授权」**
新设备需要开通使用授权。请加作者 QQ **2054793161** 联系，批准后回到 App 点「重新校验」。

**提示「这个包不是给本机打的」**
书籍数据绑定了设备。换了手机要重新生成一份。

**评论是空的 / 段落下面没有数字**
先确认正文和评论两个数据文件都导入了。只有正文不会有段评。

**翻页时误触弹出评论**
安卓可以在设置里关掉「分页翻书」，回到上下连续滚动；分页模式下点击本来就是用来看段评的。

**番外在哪里**
目录页的「番外」入口。完整版有全部番外，体验版只有「冬景（上）/（下）」两篇。

**升级后版本号还是旧的**
下载目录里可能留着同名旧文件。删掉旧的再装，或者认准文件名里的版本号。

**换了新手机怎么办**
新设备会变成「等待授权」，需要重新开通授权，并且需要一份针对新设备生成的数据包。

**提示检测到代理 / VPN**
日常使用不受影响，只是建议阅读时关掉，避免被误判。

## 时间线数据来源

App 里的「时间线」是**读者社区整理**的辅助资料，不是原著设定：

- 坐标系「捡鉴元年 = 李项平拾鉴之年 = 0」是书迷社区的约定，书中没有统一历法；
- 年份锚点、人物年龄 / 修为 / 族谱世次来自公开讨论与读者整理的资料；
- 捡鉴 198 年之后的章节（约 36%）没有一手年份证据，年份是按趋势外推的「推定值」，界面用橙色区分；
- 人物年龄可能有 ±1~3 岁偏差，修为缺失时留空不猜。

时间线仅用于辅助阅读，与原著设定冲突时以正文为准。数据由社区整理者提供，
