# 照玄微

一个把「段落评论」嵌进正文的阅读器 —— 每段末尾显示评论数，点一下就能看这一段的讨论，像弹幕一样跟着剧情走。

支持 iPhone / iPad 和 Android。

## 第一次使用（正式版）

1. **安装并打开** —— 第一次会显示「等待授权」
2. **导入书籍数据** —— 点「选择书籍数据」，选中随附的数据文件；也可以把文件放进 App 的「文件」目录后重新打开
3. **输入口令** —— 如果数据带口令，会弹窗要求输入
4. **等管理员批准** —— 批准后在 App 里点「重新校验」，就能开始读了

书籍数据通常有三个文件：**正文**、**评论**、**时间线**。
正文和评论都要导入，评论才会显示；时间线是可选包，导入后章节标题下会显示年份和出场人物。

## 怎么用

| 操作 | 效果 |
|---|---|
| **单击段落** | 打开这一段的评论（段末的数字是评论数） |
| **长按屏幕** | 呼出顶栏菜单（目录、搜索、设置） |
| **上下滚动** | 一直往下读，读完一章自动接下一章，不用翻页 |
| **单击章节标题** | 看整章的讨论 |
| **顶栏目录按钮** | 跳到任意章节，也能搜索全文 |
| **评论面板右滑** | 关闭评论（下滑也可以） |
| **章标题下的时间卡片** | 显示本章发生在「捡鉴」哪一年、出场人物的年龄 / 世代 / 修为 |
| **目录 / 时间线页** | 目录里每章带年份；「时间线」页可按章节、人物、年份搜索并跳章 |

设置里可以调字号、行距、页边距、段落间隔，以及切换纸白 / 米黄 / 夜间三种背景。
「时间线」设置里可以单独开关：章标题下的年份与人物、悬浮顶栏的年份，
以及世次显示用「第N代」还是「第N世」。

阅读位置会自动记住，下次打开直接回到上次读到的地方。

## 常见问题

**打开后显示「等待授权」**
新设备需要开通使用授权。请到 QQ 群（416751032）或发布页联系作者；批准后回到 App，点「重新校验」。

**提示「这个包不是给本机打的」**
书籍数据绑定了设备。换了手机要重新生成一份。

**评论是空的**
先确认两个数据文件都导入了（正文 + 评论）。如果只有正文，段落下面不会有数字。

**升级后版本号还是旧的**
下载目录里可能留着同名旧文件。删掉旧的再装，或者认准文件名里的版本号。

**换了新手机怎么办**
新设备会变成「等待授权」，需要重新开通授权，并且需要一份针对新设备生成的数据包。

**提示检测到代理 / VPN**
日常使用不受影响，只是建议阅读时关掉，避免被误判。

## 时间线数据来源

App 里的「时间线」是**读者社区整理**的辅助资料，不是原著设定：

- 坐标系「捡鉴元年 = 李项平拾鉴之年 = 0」是书迷社区的约定，书中没有统一历法；
- 年份锚点、人物年龄 / 修为 / 族谱世次来自公开讨论与读者整理的资料；
- 捡鉴 198 年之后的章节（约 36%）没有一手年份证据，年份是按趋势外推的「推定值」，界面用橙色区分；
- 人物年龄可能有 ±1~3 岁偏差，修为缺失时留空不猜。

时间线仅用于辅助阅读，与原著设定冲突时以正文为准。数据由社区整理者提供，
