# 照玄微

一个把「段落评论」嵌进正文的阅读器 —— 每段末尾显示评论数，点一下就能看这一段的讨论，像弹幕一样跟着剧情走。

支持 iPhone / iPad 和 Android。

---

## 下载

到 **[Releases](https://github.com/yhgeo/xianjian-reader-update/releases/tag/latest)** 页面下载最新版本。

| 平台 | 文件 | 说明 |
|---|---|---|
| Android | `XianJianReader-enc-x.x.x.apk` | 直接安装。首次需要在系统里允许「安装未知来源应用」 |
| iPhone / iPad | `XianJianReader-enc-x.x.x.ipa` | 未签名。需要用自签工具安装（AltStore、Sideloadly、TrollStore 等） |

> 安装包文件名带版本号，升级时认准新的那个。旧的可以删掉，避免装错。

## 第一次使用

1. **安装并打开** —— 第一次会显示「等待授权」
2. **导入书籍数据** —— 点「选择书籍数据」，选中随附的数据文件；也可以把文件放进 App 的「文件」目录后重新打开
3. **输入口令** —— 如果数据带口令，会弹窗要求输入
4. **等管理员批准** —— 批准后在 App 里点「重新校验」，就能开始读了

书籍数据通常是两个文件：一个正文，一个评论。两个都要导入，评论才会显示。

## 怎么用

| 操作 | 效果 |
|---|---|
| **单击段落** | 打开这一段的评论（段末的数字是评论数） |
| **长按屏幕** | 呼出顶栏菜单（目录、搜索、设置） |
| **上下滚动** | 一直往下读，读完一章自动接下一章，不用翻页 |
| **单击章节标题** | 看整章的讨论 |
| **顶栏目录按钮** | 跳到任意章节，也能搜索全文 |
| **评论面板右滑** | 关闭评论（下滑也可以） |

设置里可以调字号、行距、页边距、段落间隔，以及切换纸白 / 米黄 / 夜间三种背景。

阅读位置会自动记住，下次打开直接回到上次读到的地方。

## 常见问题

**打开后显示「等待授权」**
新设备需要管理员在后台批准。批准后回到 App，点「重新校验」。

**提示「这个包不是给本机打的」**
书籍数据绑定了设备。换了手机要重新生成一份。

**评论是空的**
先确认两个数据文件都导入了（正文 + 评论）。如果只有正文，段落下面不会有数字。

**升级后版本号还是旧的**
下载目录里可能留着同名旧文件。删掉旧的再装，或者认准文件名里的版本号。

**换了新手机怎么办**
新设备会变成「等待授权」，需要重新批准，并且需要一份针对新设备生成的数据包。

**提示检测到代理 / VPN**
日常使用不受影响，只是建议阅读时关掉，避免被误判。
